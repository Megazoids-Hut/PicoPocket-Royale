# PicoPocket Royale

Another Pi Pico (RP2350 or RP2040) DIY handheld based on the open source PicoPad schematic. 

This DIY handheld is similar to my previous PicoPocket handheld but with a bigger form factor, larger 2.8 inch screen, PAM8302A amp, 3.5mm headphone jack and volume wheel. 

I'm not doing a "how-to" build guide because I don't think it's worth it. If you have questions/problems, drop me a line.

# Story

PicoPocket Royale is a handheld device that works on either the Raspberry Pi Pico (RP2040) or Raspberry Pi Pico 2 (RP2350). It's based on the [Picopad schematic](https://github.com/Pajenicko/Picopad/blob/main/hardware/schematics/picopad-v1.0.pdf)), and operates on the [PicoLibSDK](http://www.breatharian.eu/hw/picolibsdk/index_en.html) by Miroslav Nemecek.
