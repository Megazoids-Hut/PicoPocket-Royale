PicoLibSDK
----------

These are inverted colour version of the PicoLibSDK software (date: 02/07/2026) for PicoPad RP2040 (!PicoPad10) and PicoPad RP2350 (!PicoPad20) needed for the PicoPocket Royale to function.

Doom 
----

The !PicoPad20 directory contains DOOM/DOOM.UF2

This is an inverted colour version based on https://github.com/svermigo/rp2040-doom
It differs from svermigo's DOOM.UF2 in exactly 6 bytes — the two inversion instructions and the 4-byte CRC field.
